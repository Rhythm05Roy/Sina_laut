## Overview

**Sina Laut** is a production-grade asynchronous backend that takes structured brand and product inputs and orchestrates an AI image generation pipeline to produce marketplace-ready visuals.

The system mirrors a real UI flow: **project setup → brand CI → product info → image brief selection → async generation → polling for results.**

Key design decisions:
- **Fully async** — image generation jobs are decoupled from HTTP via background workers, so clients never block waiting for compute
- **Schema-first** — every input stage is validated with Pydantic models, preventing malformed data from entering the pipeline
- **Modular services** — prompt builder, AI client, background remover, and keyword crawler are each isolated, making individual components swappable
- **Stub-safe** — runs fully without a real API key, returning placeholder URLs for local development

## Quickstart

**1. Clone and set up environment**
```bash
git clone https://github.com/Rhythm05Roy/Sina_laut.git
cd Sina_laut
python -m venv .venv
source .venv/bin/activate        # Linux / macOS
# .venv\Scripts\activate         # Windows PowerShell
pip install -r requirements.txt
```

**2. Configure environment**
```bash
cp .env.example .env
# Edit .env — set NANO_BANANA_API_KEY if you have one
# Without a key, the service returns placeholder URLs (safe for dev)
```

**3. Run the server**
```bash
uvicorn app.main:app --reload --port 8000
```

**4. Open interactive docs**
```
http://localhost:8000/api/docs
```

## API Reference

### `GET /api/health`
Returns service health status.

```json

```

### `POST /api/ai/generate`
Starts an async image generation job. Returns a `job_id` immediately.

<details>
<summary><b>Full example request body</b></summary>

```json
{
  "project": {
    "project_name": "Softvanced Launch",
    "brand_name": "Softvanced",
    "product_category": "Drinkware",
    "target_marketplaces": ["amazon"]
  },
  "brand": {
    "logo_url": "https://example.com/logo.png",
    "primary_color": "#1a1a2e",
    "secondary_color": "#a78bfa",
    "font_heading": "Inter",
    "font_body": "Roboto"
  },
  "product": {
    "sku": "SV-WB-001",
    "title": "Softvanced Water Bottle",
    "short_description": "Premium aluminium water bottle — rough, tough, and carry-ready.",
    "usps": ["No harmful materials", "Premium finish", "Easy to carry"],
    "keywords": { "amazon": ["aluminium bottle", "premium water bottle"] },
    "languages": ["en"]
  },
  "assets": [
    { "type": "product_photo", "url": "https://example.com/water-bottle.jpg" }
  ],
  "image_briefs": [
    {
      "slot_name": "hero_dark",
      "instructions": "Dark dramatic background with smoke effect, product angled at 15°",
      "emphasis": ["brand logo", "product silhouette"],
      "style": "Premium, cinematic, high-contrast"
    },
    {
      "slot_name": "feature_card",
      "instructions": "Light gradient background, product centered, feature icons around it",

}
```

**Response**
```json
{ "job_id": "a3f9c2d1-...", "status": "queued" }
```

---

### `GET /api/ai/jobs/{job_id}`
Poll for job status and retrieve generated image URLs when complete.

```json
{
  "job_id": "a3f9c2d1-...",
  "status": "completed",
  "images": [
    { "slot_name": "hero_dark",    "url": "https://..." },
    { "slot_name": "feature_card", "url": "https://..." }
  ]
}
```

| Status | Meaning |
|--------|---------|
| `queued` | Job accepted, waiting for worker |
| `processing` | Background worker running |
| `completed` | Images ready at returned URLs |
| `failed` | Error during generation — check logs |

## How Prompt Construction Works

The `prompt_builder` service combines four input layers into a single coherent image prompt per slot:

```
Brand CI (colors, fonts, logo)
        +
Product Info (title, USPs, keywords)
        +
Image Brief (slot instructions, style, emphasis)
        +
Marketplace Rules (platform-specific compliance)
        =
  Final image generation prompt
```

This ensures every generated image stays on-brand and marketplace-compliant without manual prompt engineering per product.

## Development Notes

- **No API key?** — The AI client returns deterministic placeholder URLs so the full pipeline can be tested locally without any external dependency.
- **Swapping the AI backend** — Replace `app/services/ai_client.py` to point at any image generation API (DALL·E, Stability, Midjourney, etc.) — the orchestrator is backend-agnostic.
- **Background removal** — `background_remover.py` is a stub with a clear integration point for Remove.bg, Rembg, or any segmentation model.
- **Keyword crawler** — `keyword_crawler.py` stub is ready to connect to SEO APIs (DataForSEO, Jungle Scout, etc.) for automatic keyword enrichment.
